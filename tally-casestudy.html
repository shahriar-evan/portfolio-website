// The problem

Same product, five different prices

Amazon has one price, AliExpress another, Daraz a third. Delivery is charged on top, and often in a different currency.

So shoppers open four or five store sites one by one, add each delivery fee themselves, and convert currencies by hand. Many give up and buy from the first store they saw, which usually means paying more than they needed to.

// The solution

One search, one sorted list

Tally answers four questions on one screen: which websites sell the product, what each one charges, what delivery costs, and what the total comes to. The number at the top is what the shopper actually pays.

01

Search once

Type the product. Tally pulls every listing for it from every store in the network.

02

Delivery goes in

Each row shows price plus delivery as one total, so a cheap price with costly shipping can't hide.

03

Cheapest on top

Results are sorted by that total. Tap a store and its product page opens to buy.

// For shoppers

What users get

Saves money

  • Every store's price side by side from one search
  • The real total with delivery included
  • The cheapest store marked with a green Lowest badge
  • The gap between cheapest and priciest shown on every product

Saves time

  • No visiting five websites
  • Prices open in your own currency, picked from where you are
  • No manual maths or currency conversion
  • Buy opens the store's product page directly

Easy to find things

  • Categories: Electronics, Fashion, Accessories, Digital
  • Filters: country, category, store, price range
  • Sorting: lowest price, best value, highest rating
  • Ratings, review counts and similar products on every page

No hassle, no tricks

  • No account and no browser extension
  • Works well on phones and installs like an app
  • Light and dark mode
  • Referral fees never change the order. Cheapest total is always first
// Business model

How Tally earns

Revenue

Affiliate commission

Each store's tracking ID (like Amazon's tag=) is added to every link, and each offer can hold its own affiliate link. When a shopper buys, the store pays a commission.

Insight

Commission coverage

The admin panel shows how many offers already earn, which still need a link, and how many clicks each product and store gets.

Operations

Admin panel

Manage products, stores, prices and affiliate links from /admin. Offers without a link still send shoppers to a working store search page.

Where it stands · November 2026

The site, brand and admin panel are built. Listed honestly, so nothing is overclaimed:

  • Manual pricesPrices are entered in the admin panel, not pulled from stores automatically. The demo catalogue has 20 products.
  • Fixed exchange ratesCurrency conversion uses a reference rate that isn't updated daily.
  • Affiliate approvalCommission starts once each store's program approves Tally and its links are added in the admin panel.
  • Database pendingThe live site needs a cloud database connected before products appear.
  • No unproven claimsUser numbers and store-vetting claims can't be backed up yet, so the site doesn't make them.
